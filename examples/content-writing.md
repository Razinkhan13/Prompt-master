# Content Writing Examples

Practical examples of prompts for various content creation tasks.

## Blog Writing

### Example 1: Technical Blog Post

**Prompt:**
```
Write a 1200-word blog post titled "Understanding React Hooks: A Practical Guide"

Target Audience: Junior to mid-level developers
Tone: Educational but approachable, avoid condescension

Structure:
1. Introduction - Why hooks matter (150 words)
2. useState - with code example (300 words)
3. useEffect - with code example (300 words)
4. Custom Hooks - practical example (300 words)
5. Best Practices - 5 key tips (200 words)
6. Conclusion - call to action (150 words)

Requirements:
- Include 3-4 code examples
- Use analogies for complex concepts
- Add subheadings for easy scanning
- Include practical use cases
- End with resources for further learning

SEO Keywords: React hooks, useState, useEffect, custom hooks (use naturally)
```

### Example 2: Company Blog Post

**Prompt:**
```
Write a 600-word blog post announcing our new product feature: AI-powered email categorization

Company: EmailPro (email management software)
Audience: Small business owners and busy professionals
Tone: Excited but professional, benefit-focused

Include:
- Hook: Start with a pain point (email overload)
- Feature overview: What it does
- Benefits: Time saved, better organization, reduced stress
- How it works: Brief, non-technical explanation
- Customer quote: [Make up a realistic testimonial]
- Call-to-action: "Try it free for 30 days"

Avoid: Technical jargon, lengthy explanations
Focus on: Benefits over features, real-world impact
```

## Marketing Copy

### Example 3: Landing Page Copy

**Prompt:**
```
Write landing page copy for a productivity app called "FocusFlow"

Target: Remote workers struggling with distractions

Sections needed:

1. Hero Section (above the fold):
   - Headline: Attention-grabbing (8-10 words)
   - Subheadline: Clear value proposition (15-20 words)
   - CTA button text

2. Problem Section (100 words):
   - Identify 3 key pain points

3. Solution Section (150 words):
   - How FocusFlow solves each problem
   - Key features (bullet points)

4. Social Proof (50 words):
   - User stats: "Join 50,000+ professionals"
   - Brief testimonial

5. Final CTA (50 words):
   - Create urgency
   - Guarantee/risk reversal

Tone: Empathetic, confident, motivating
Style: Short sentences, scannable, benefit-driven
```

Create a 3-email welcome sequence for new subscribers to our fitness app:

## Social Media Content

### Example 5: LinkedIn Post Series

**Prompt:**
```
Create 5 LinkedIn posts for a career coach sharing job search tips:

Format for each:
- Hook (first line must grab attention)
- Body (3-4 short paragraphs or bullet points)
- Call-to-action or question to encourage comments
- Relevant hashtags (4-5)

Topics:
1. How to optimize LinkedIn profile headline
2. Networking without being salesy
3. Following up after job interviews
4. Handling job rejection professionally
5. Negotiating salary confidently

Tone: Professional but warm, helpful, experience-based
Include: Personal anecdotes or examples
Length: 150-200 words each
```

### Example 6: Twitter Thread

**Prompt:**
```
Write a Twitter thread (8-10 tweets) about "5 Python tips that saved me hours"

Format:
- Tweet 1: Hook tweet with thread announcement
- Tweets 2-6: One tip per tweet with code example
- Tweet 7: Bonus tip
- Tweet 8: Recap and CTA (follow for more)

Requirements:
- Each tweet under 280 characters
- Include code snippets where relevant
- Use emojis sparingly (1-2 per tweet)
- Number each tip
- Make it skimmable
- Add value, not just basics

Tone: Friendly, knowledgeable, sharing genuinely helpful insights
```

## Product Descriptions

### Example 7: E-commerce Product Description

**Prompt:**
```
Write a product description for: Premium Ergonomic Office Chair

Key Features:
- Adjustable lumbar support
- Breathable mesh back
- 4D armrests
- Tilt mechanism
- Weight capacity: 300 lbs
- 5-year warranty

Target Customer: Remote workers, office professionals with back pain
Price Point: $450 (premium)

Structure:
1. Opening hook (30 words): Paint a picture of comfort
2. Features & Benefits (150 words): Each feature tied to a benefit
3. Specifications (bullet points)
4. Trust elements: Warranty, materials, certifications
5. Call-to-action

Tone: Premium quality, health-focused, confident
Persuasion tactics: Address pain points, emphasize long-term value
```

### Example 8: SaaS Product Description

**Prompt:**
```
Write a product page description for "DataSync Pro" - a data integration tool

Target Audience: Tech-savvy business operations managers
Length: 300 words

Include:
- One-sentence value proposition

## Email Writing

### Example 10: Professional Email

**Prompt:**
```
Write a professional email for this situation:

Context: You're a project manager needing to inform stakeholders about a 2-week delay
Recipient: Senior leadership team
Reason: Key team member medical leave + unexpected technical complexity

Email should:
- Open with clear, direct statement of delay
- Explain reasons professionally (no excuses)

## Tips for Effective Content Prompts

### 1. Define Your Audience Precisely
```
❌ Generic: "Write for business people"
✅ Specific: "Write for solo entrepreneurs, aged 30-45, struggling with time management"
```

### 2. Specify Tone with Examples
```
Instead of: "Friendly tone"
Use: "Friendly like a knowledgeable colleague, not a textbook. Think casual but professional."
```

### 3. Provide Structure
```
Include:
- Desired word count
- Section breakdown
- Heading structure
- Opening/closing requirements
```

### 4. Set Clear Goals
```
What should the content achieve?
- Educate?
- Convert?
- Engage?
- Build trust?
```

### 5. Include Constraints
```
- Keywords to include (or avoid)
- Length limits
- Style guidelines
- Brand voice rules
```

### 6. Request Specific Elements
```
Must include:
- Call-to-action
- Statistics/data
- Examples
- Metaphors/analogies
```

## Common Content Patterns

### Educational Content Pattern
```
Write a [length] [content type] about [topic] for [audience].

Structure:
1. Problem/question (why this matters)
2. Background/context
3. Solution/answer with examples
4. Application (how to use this)
5. Conclusion with takeaway

Tone: [specify]
Include: [examples, analogies, data, etc.]
```

### Persuasive Content Pattern
```
Write [content type] to convince [audience] to [action].

Include:
1. Attention-grabbing opening
2. Problem identification (pain points)
3. Solution presentation
4. Proof (testimonials, data, case studies)
5. Objection handling
6. Strong call-to-action

Focus on benefits, not features.
Tone: [specify]
```

### Storytelling Pattern
```
Write a story about [subject] that [achieves goal].

Story elements:
- Character: [who]
- Challenge: [obstacle]
- Journey: [what happened]
- Transformation: [how they changed]
- Lesson: [what it means]

Tone: [specify]
Length: [words]
Purpose: [educate/inspire/entertain]
```
