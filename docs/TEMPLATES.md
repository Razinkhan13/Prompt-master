# Prompt Templates

Ready-to-use prompt templates for common tasks. Copy and customize these templates for your specific needs.

## Content Creation Templates

### Blog Post Generation
```
Write a [word count] blog post about [topic].

Target Audience: [describe audience]
Tone: [professional/casual/technical/friendly]
Key Points to Cover:
- [point 1]
- [point 2]
- [point 3]

Include:
- An engaging introduction
- [number] main sections with subheadings
- Practical examples
- A conclusion with call-to-action

SEO Keywords to include: [keyword1, keyword2, keyword3]
```

### Social Media Content
```
Create [number] social media posts about [topic] for [platform].

Requirements:
- Platform: [Twitter/LinkedIn/Instagram/Facebook]
- Character limit: [if applicable]
- Tone: [engaging/professional/humorous]
- Include: [hashtags/emojis/call-to-action]
- Target audience: [describe]

Goal: [increase engagement/drive traffic/build awareness]
```

### Product Description
```
Write a compelling product description for:

Product Name: [name]
Category: [category]
Key Features:
- [feature 1]
- [feature 2]
- [feature 3]

Target Customer: [describe]
Unique Selling Points: [USPs]
Tone: [persuasive/informative/luxury/budget-friendly]
Length: [word count]

Include benefits, not just features. Address customer pain points.
```

## Code-Related Templates

### Code Generation
```
Create a [language] [function/class/script] that [description of functionality].

Requirements:
- Input: [describe inputs]
- Output: [describe expected output]
- Constraints: [any limitations or requirements]
- Error handling: [specify approach]
- Performance: [any performance requirements]

Include:
- Clear variable names
- Inline comments for complex logic
- Docstrings/documentation
- Example usage
```

### Code Review
```
Review the following [language] code and provide feedback on:

1. Code quality and readability
2. Potential bugs or errors
3. Performance optimization opportunities
4. Security vulnerabilities
5. Best practices adherence

Code:
```[language]
[paste code here]
```

Provide specific suggestions for improvement with examples.
```

### Debugging Assistance
```
I'm experiencing [describe the issue] in my [language] code.

Error Message:
```
[paste error message]
```

Relevant Code:
```[language]
[paste code]
```

Context:
- What I'm trying to do: [explanation]
- What's happening instead: [description]
- What I've already tried: [attempts]

Help me:
1. Identify the root cause
2. Suggest a solution
3. Explain why the issue occurs
```

1. Key statistics (mean, median, ranges)
2. Notable patterns or trends
3. Outliers or anomalies
4. 3-5 main insights
5. Recommendations based on findings

[paste text here]
```

## Educational Templates

### Explanation Request
```
Explain [concept/topic] as if you're teaching it to [target audience level].

Requirements:
- Use simple language and avoid jargon
- Provide 2-3 real-world examples
- Include analogies or metaphors
- Break down into key components
- Add practice questions if applicable

Level: [beginner/intermediate/advanced]
Length: [brief/moderate/comprehensive]
```

### Study Guide
```
Create a study guide for [subject/topic].

Include:
1. Key Concepts (with brief explanations)
2. Important Terms and Definitions
3. Practice Questions ([number])
4. Common Mistakes to Avoid
5. Tips for Mastery

Target: [exam/certification/course]
Difficulty: [basic/intermediate/advanced]
```

## Research Templates

2. Identify key researchers and papers

```

Product/Service: [name]

Address:
1. What problem does it solve?
2. How does it solve it?
3. What makes it unique?

```

## Tips for Using Templates

1. **Customize**: Always adapt templates to your specific needs
2. **Be Specific**: Replace bracketed placeholders with detailed information
3. **Iterate**: Start with the template and refine based on results
4. **Combine**: Mix elements from different templates when needed
5. **Test**: Try variations to find what works best for your use case
